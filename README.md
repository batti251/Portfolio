# 🌐 Portfolio – Angular 22

This is my personal **portfolio website**, built with **Angular 22**, showcasing my projects, skills, and frontend development experience.  
The focus lies on clean architecture, component-based design, and modern Angular best practices.

---

## 📌 Overview

- Component-based Angular architecture
- Responsive layout for all screen sizes
- Clean separation of logic, layout, and styling
- Built with modern Angular features and tooling

---

## 🛠️ Tech Stack

- **Angular 22** (CLI: 22.1.2)
- **TypeScript**
- **HTML5 & SCSS**
- **Angular Material**

---

## 🧩 Angular Concepts Used

- Standalone & reusable components
- Angular Router
- Reactive & Template-driven Forms
- Services & Dependency Injection
- Animations & state handling
